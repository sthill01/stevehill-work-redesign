# Steve Hill Work Redesign

This repository is a redesign sandbox for `stevehill.work`.

It is intentionally separate from the production `BI-portfolio` repository so the visual system,
page structure, and content migration can be reviewed safely before any live replacement.

## Current scope

- `stevehill.work.html` - homepage
- `HowIWork.html` - How I Work
- `Dashboards.html` - dashboard library
- `Examples.html` - examples hub
- `Resume.html` - resume
- `Case-Foxit.html`
- `Case-Netgain.html`
- `Case-Squirrel.html`
- `Case-UTA.html`

## Local preview

Serve the repo as a static site and open:

- `/stevehill.work.html`
- `/HowIWork.html`
- `/Dashboards.html`
- `/Examples.html`
- `/Resume.html`

## Notes

- This repo is the review and iteration track for the redesign.
- The production portfolio remains in the separate `BI-portfolio` repository.
